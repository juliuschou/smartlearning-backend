# SmartLearning Backend

A NestJS 11 backend service with configuration, validation, and structured logging (Pino) baseline.

## Prerequisites

- Node.js (see `@types/node` major version)
- npm

## Quick start

```bash
# 1. Configure environment
cp .env.example .env

# 2. Install dependencies
npm install

# 3. Run in dev mode (hot reload)
npm run start:dev
```

The server boots on **port 3000** (configurable via `PORT` in `.env`). On a successful boot you should see:

```
Application is running on port 3000
```

> Note: `AppModule` currently has no controllers/providers, so routes return 404 until feature modules are added.

## Available scripts

| Script | Purpose |
|---|---|
| `npm run start:dev` | Dev mode with `--watch` (file reload) |
| `npm run start:debug` | Dev + Node debug inspector |
| `npm run start:prod` | Runs the compiled output (`node dist/main`) |
| `npm run build` | Compile via `nest build` → `dist/` |
| `npm run lint` | ESLint with auto-fix |
| `npm run format` | Prettier write |
| `npm test` | Jest unit tests |
| `npm run test:e2e` | e2e tests via `test/jest-e2e.json` |
| `npm run test:cov` | Coverage report |

## Project layout

```
src/
  main.ts            # Bootstrap: global ValidationPipe + Pino logger
  app.module.ts      # Root module: ConfigModule + LoggerModule
  app.module.spec.ts # Unit test for AppModule
test/                # e2e tests
dist/                # Compiled output (generated by `npm run build`)
```

## Configuration

Environment variables are loaded globally via `@nestjs/config` (see `.env.example`):

| Variable | Default | Description |
|---|---|---|
| `PORT` | `3000` | HTTP listen port |
| `NODE_ENV` | `development` | Controls Pino log level/transport (`production` → raw JSON `info`; otherwise pino-pretty `debug`) |

## Verification

npm run start:dev           # start the server
