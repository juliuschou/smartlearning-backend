# SmartLearning metrics dashboard inventory

These panels are an OPS-1.8 handoff for a Prometheus/Grafana deployment. PromQL intentionally uses only the fixed CP7 labels.

| Panel                     | PromQL                                                                                                                                  | Unit       | Interpretation / handoff                                                                                                        |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| HTTP throughput           | `sum(rate(smartlearning_http_requests_total[5m]))`                                                                                      | requests/s | Overall completed request throughput. Compare with load profile and deployment metadata.                                        |
| HTTP 5xx ratio            | `sum(rate(smartlearning_http_requests_total{status_class="5xx"}[5m])) / clamp_min(sum(rate(smartlearning_http_requests_total[5m])), 1)` | ratio      | Unexpected server-error ratio; correlate with readiness and dependency panels.                                                  |
| HTTP latency p50          | `histogram_quantile(0.50, sum by (le) (rate(smartlearning_http_request_duration_seconds_bucket[5m])))`                                  | seconds    | Typical request latency.                                                                                                        |
| HTTP latency p95          | `histogram_quantile(0.95, sum by (le) (rate(smartlearning_http_request_duration_seconds_bucket[5m])))`                                  | seconds    | API SLO and overload signal.                                                                                                    |
| HTTP latency p99          | `histogram_quantile(0.99, sum by (le) (rate(smartlearning_http_request_duration_seconds_bucket[5m])))`                                  | seconds    | Tail latency; investigate saturation and slow dependencies.                                                                     |
| Dependency readiness      | `smartlearning_readiness_dependency_status`                                                                                             | 0/1        | One means the latest observed dependency check was healthy. Keep `database`, `realtime_redis`, and `login_rate_limit` separate. |
| Login rate-limit hits     | `rate(smartlearning_login_rate_limit_hits_total[5m])`                                                                                   | hits/s     | Sustained login limiting; tune the alert threshold to real traffic and abuse baseline.                                          |
| Realtime retries          | `rate(smartlearning_realtime_publish_failures_total{outcome="retry"}[5m])`                                                              | failures/s | Persisted transient publish failures. Check queue age and dependency health.                                                    |
| Realtime dead transitions | `rate(smartlearning_realtime_publish_failures_total{outcome="dead"}[5m])`                                                               | failures/s | Persisted dead-letter transitions; treat as high-severity correctness signal.                                                   |
| Job runs                  | `sum by (bg_job, outcome) (rate(smartlearning_job_runs_total[15m]))`                                                                       | runs/s     | Auto-close and retention run outcomes. Overlap/destroyed scheduler calls are not runs.                                          |
| Job duration p95          | `histogram_quantile(0.95, sum by (bg_job, outcome, le) (rate(smartlearning_job_duration_seconds_bucket[15m])))`                            | seconds    | Background job tail duration by fixed job/outcome.                                                                              |
| Job items                 | `sum by (bg_job, result) (rate(smartlearning_job_items_total[15m]))`                                                                       | items/s    | Closed/failed auto-close items and selected/deleted retention items.                                                            |
| Readiness check outcomes  | `sum by (dependency, outcome) (rate(smartlearning_readiness_checks_total[5m]))`                                                         | checks/s   | Check activity and observed outcomes; this is observational, not readiness authority.                                           |
| Retention oldest due age  | `smartlearning_retention_oldest_due_age_seconds`                                                                                        | seconds    | Age of the oldest due archive; alert before backlog becomes operationally urgent.                                               |
| Retention due backlog     | `smartlearning_retention_due_backlog`                                                                                                   | archives   | Current due archive count; inspect before enabling any purge gate.                                                              |
| Manifest lag              | `smartlearning_retention_manifest_lag_seconds`                                                                                          | seconds    | Export watermark lag; requires a provider-backed immutable store before production use.                                         |
| Manifest dead records     | `smartlearning_retention_manifest_dead_records`                                                                                         | records    | Non-zero means durable export failure; stop and investigate.                                                                    |
| Reconciliation failures   | `rate(smartlearning_retention_reconciliation_failures_total[15m])`                                                                      | failures/s | Reconciliation failures; keep apply disabled until reviewed.                                                                    |
| Retention purge last success | `smartlearning_retention_purge_last_success_seconds`                                                                                 | epoch s    | Unix epoch of the last successful purge run; absent/stale means the scheduler stopped succeeding (see `RetentionPurgeNoRecentSuccess`). |

## Handoff notes

- Add build version, topology, Node/PostgreSQL/Redis versions, scrape interval, and load-test profile as dashboard annotations supplied by OPS; none are metric labels.
- A missing database readiness series is a signal-loss condition and must be alerted separately from a gauge value of `0`.
- `realtime_redis=0` is optional degradation in supported modes; `login_rate_limit=0` is critical only when the required login limiter is unavailable.
- Do not add account IDs, IPs, request IDs, resource IDs, URLs, query strings, tokens, hashes, question text, answer content, or error messages as labels.
